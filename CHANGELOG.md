## [Unreleased]

### Added
- **ADR 0008 — Personal Agents Runtime Relocation to OpenCode Go**: `docs/adr/0008-personal-agents-runtime-relocation-to-opencode-go.md` (status **Accepted** 2026-11-17 — build gates 6/6, QA live matrix 7/7 on the laptop, remote runtime turn 1/1 on homesrv) — records the one-invoice decision, the 7-row mapping with per-agent rationale, the `provider/model#variant` syntax contract and builder failure modes, the residency/training gate findings, the luna pool sharing, the homesrv verification record, and the alternatives considered (native google, deepseek-v4.1-flash, beam-free, Antigravity port — parked).
- **`oc` preflight now reports `GEMINI_API_KEY` as OPTIONAL (rollback path)**: the advisory text was reworded from "the 7 personal agents will fail at runtime" to "no agent consumes this key since ADR 0008 — it is the documented rollback to the native `google` provider". Warning retained deliberately so the rollback cannot break silently; `check_env_vars` hard-die behavior for vars that DO matter is unchanged.
- **Troubleshooting rows for the new failure modes** (`AGENTS.md`): `provider.no-route` from a bad/unsupported `#variant` suffix, HTTP 400 residency gate, HTTP 400 training gate, silent account-default substitution when `model:` is empty/null, the YAML-comment-before-`#` trap, "variant not auditable from the console export", the **2.2.5 silent agent-drop** (a `model: null` frontmatter removes the agent from the listing with no log line at all — `agent file skipped` does not exist in that binary, `--print-logs` filters return empty, no `--archived` flag), the `session_id` (2.2.5) vs `sessionID` (2.3.0) **schema skew** for consumer scripts, and **local `cost` reading 0 on both nodes** (the $ ceiling is console-only).
- **Builder model-shape guard (pre-emission validation)**: `builder/main.go` now validates every resolved `model:` value BEFORE the first `os.WriteFile`, replacing three silent-failure paths with hard aborts. `validateModelValue` enforces ordered rules on each value — `EMPTY_VALUE`, `WHITESPACE` (the `x #medium` YAML-comment trap), `HASH_FIRST`, `MULTI_HASH`, `MISSING_SEGMENT`, `EMPTY_SEGMENT`, `ILLEGAL_CHARACTERS`, `PROVIDER_NOT_ALLOWLISTED` — against `^[A-Za-z0-9._-]+/[A-Za-z0-9._-]+(#[A-Za-z0-9._-]+)?$`, and `allowedModelProviders` gates the provider prefix to `opencode-go`; reverting a personal agent to native `google` now requires adding `"google"` to that allowlist in a reviewed commit, because the `provider.use google allow` policy floor permits the route but does not authorize the build. `validateProfile` replaces the `v.(string)` type-assertion panic with a reported error and aggregates ALL violations in sorted key order; `preflightModelKeys` fails the build when a template references a key the profile does not define (previously: a warning, with the literal `{{MODEL:key}}` left in the compiled agent); the warn-and-leave-literal path in `resolveModelPlaceholders` is deleted. Also covers the `config.json` consumers (`model`, `agents.title.model`, `agents.explore.model`); no `#`-unsafe `${VAR}`/dotenv route was introduced. Stdlib-only preserved (go.mod: zero requires). New `builder/main_test.go` (table-driven: 6 tests, `go test -race` clean). Proven non-behavioral for the current roster: post-guard build emits **all 16 artifacts byte-identical** to the pre-change baseline; abort path verified (a deliberately broken value exits 1 with **zero files written**). Documented blind spot: the guard validates SHAPE only — a well-formed but non-existent variant (`gemini-4-argon#ultra`) still reaches the gateway and dies at first turn with `provider.no-route`, because no local variant catalog exists.
- **Elephant-Goldfish Model (EGM) Adversarial Spec Review Protocol**: Codified adversarial review mechanism in Phase 1.5 across `prompts/subagent_behavior.md`, `prompts/commander_behavior.md`, `AGENTS.md`, and ADR 0003. Subagents act as hostile Goldfish critics enforcing a mandatory 3-section contract:
  - (A) Challenged Assumptions & Unstated Invariants (minimum 1 invariant attacked).
  - (B) Concrete Failure Modes (minimum 2-3 grounded failure cascades with `Trigger -> Failure Cascade -> Blast Radius`).
  - (C) Probing Architectural Questions & Trade-offs (partitioned into C.1 Technical Invariants for RFC and C.2 Product/Risk Decisions escalated to user via `question`).
  - Structured Verdicts: `BLOCKED`, `CHALLENGED`, or `CERTIFIED_WITH_MITIGATIONS` (unconditional approvals prohibited).
- **Anti-Sycophancy Rejection Gate**: Mandated Commander actively reject passive "looks good" or rubber-stamped approvals, demanding an adversarial audit before Phase 2 master planning.
- **Subagent Leaf Execution Hardening**: Enforced explicit runtime denies for child subagent spawning (`action: subagent`, `action: task`) and outbound web search (`action: websearch`) across all technical subagent templates.
- **Native Agent Policy**: Explicitly disabled unspecialized fallback agents (`general`, `build`, `plan`) in `config.json` while pinning `explore` and `title` to `{{MODEL:small_model}}`.
- **ADR 0003**: Accepted formal Architecture Decision Record `docs/adr/0003-elephant-goldfish-adversarial-review-protocol.md`.

- **Homesrv (Pi) leg of ADR 0008 VERIFIED — the relocation is no longer laptop-only** (Commander measurements, 2026-11-17, post-sync executed by the user at 19:52). PE compared the two binaries: opencode **2.2.5** (Pi) and **2.3.0** (laptop) resolve `model: opencode-go/gemini-4-argon#medium` **identically** (`Variant unavailable`, `provider.no-route`, `activeVariant` present in both) ⇒ **SAFE_TO_SYNC**. Pi `~/.config/opencode/agent/` now holds the 15 relocated files (mtime 19:52, **zero `google/` references**), with the pre-backup at `homesrv:~/backups/oc-sync/overwrites-agent-20261117-195248/`. Remote runtime turn passed: `ssh homesrv opencode run --agent finanzas --format json` → rc=0, Spanish, `step_finish.reason: stop`; the Pi's own DB reports `session_message.data.model` = `id=gemini-4-argon`, `providerID=opencode-go`, `variant=medium`. Every "sync pending" / "parity pending" / "relocation stays laptop-local" claim in `AGENTS.md`, `README.md`, `builder/README.md`, `bin/oc` and ADR 0008 was removed, not softened. Two measured limitations replace the old risk story: on 2.2.5 a broken `model:` frontmatter makes the agent **vanish with no log at all**, and the `session_message` session column is **`session_id` on 2.2.5 vs `sessionID` on 2.3.0**.
- **Corrected the homesrv service doctrine**: the Pi runs opencode as a **systemd SYSTEM unit** (`opencode.service`, active; `oc --sync` restarts it via `ssh homesrv "sudo systemctl restart opencode"`, measured at 19:52:52 CET). The previous wording in `prompts/_installed_capabilities.md` (injected into every agent system prompt, hence mirrored in the compiled `agent/*.md` until the next build) was wrong about the Pi's service and is fixed at the source; compiled artifacts are generated and were not hand-edited. Whether the Pi's service environment carries `GEMINI_API_KEY` is **not verified** — `systemctl show opencode -p Environment` returns only `PATH`, which does not display `EnvironmentFile=` variables, so it proves nothing either way.
